# Clip-Adjust

**Premiere Pro で、動画のカットとテロップのタイミングが微妙にズレる問題を、ワンクリックでまとめて直すツール。**

Mac・Windows どちらでも使えます。インストールは 3 ステップです。

---

## こんな悩みありませんか？

動画編集をしていて、こんな経験ありませんか？

- トーク動画を**カット編集したあと**、別トラックに**テロップを並べた**
- でも、カットした瞬間とテロップが出るタイミングが **数フレームだけズレている**
- テロップ 1 本ずつ手で「あと 2 フレームだけ右へ…」と直すのが地獄

**Clip-Adjust はこれを一瞬で直します。**

> ベースの動画クリップが「切り替わる瞬間」に、テロップを **自動でピタッと寄せる**。
> そういうツールです。

---

## こんな動きをします

たとえば、**V1 に動画**、**V2 にテロップ**を置いたタイムラインがあるとします。

```
 時間 →
V1  [動画カット①][動画カット②][動画カット③]
V2      [テロップA]    [テロップB]    [テロップC]
           ↑3F遅い      ↑2F早い       ↑ぴったり
```

このツールを実行すると：

```
V1  [動画カット①][動画カット②][動画カット③]
V2  [テロップA]  [テロップB]    [テロップC]
     ↑合った     ↑合った         ↑そのまま
```

こんな風に、**カットの切り替わりにテロップの頭をそろえてくれます。**

もし「許容フレーム」で決めた数字より大きくズレているテロップは、**安全のため触りません**（勝手に遠くへ飛ばされないように）。

---

## 動作環境

- **Adobe Premiere Pro 2024 以降**（2023 以前は対応外）
- **Mac**: macOS 12（Monterey）以降
- **Windows**: Windows 10 または 11

# インストール（3 ステップ）

Premiere Pro に後付けの機能（パネル）を入れるので、**「ZXPInstaller」という小さな無料アプリ** を使います。これを 1 回入れておけば、今後 Premiere の他のパネル類もワンクリックで入れられるようになります。

## ステップ 1. ZXPInstaller を入れる（初回のみ）

1. ブラウザで **https://zxpinstaller.com** を開く
2. 右上の **「Download for Mac」** または **「Download for Windows」** をクリック
3. ダウンロードされたインストーラーをダブルクリックして、普通のアプリと同じようにインストール

> **Mac で「開発元を確認できません」と出たら:** 右クリック（Control+クリック）→「開く」→もう一度「開く」で進めます。ZXPInstaller は Adobe エコシステムで広く使われている信頼できるツールです。

> 次回以降はこの手順はスキップできます。

## ステップ 2. Clip-Adjust の `.zxp` をダウンロード

1. このページ上部の **「Releases」** をクリック
2. 最新バージョンの **「Assets」** を開き、**`Clip-Adjust-vX.Y.Z.zxp`** をクリックしてダウンロード

> `.zxp` は「Premiere のパネル」を 1 つにまとめたファイル形式です。開かずにそのまま次のステップへ。

## ステップ 3. ZXPInstaller にドラッグ＆ドロップ

1. ステップ 1 でインストールした **ZXPInstaller** アプリを起動
2. 画面の真ん中に、ダウンロードした `.zxp` ファイルを **ドラッグ＆ドロップ**
3. 「Installation Successful」と出れば成功

# 使い方

## ステップ 1. Premiere Pro を再起動

すでに Premiere を開いている場合は、一度閉じてから開き直してください。

## ステップ 2. パネルを開く

Premiere Pro のメニューから：

**ウィンドウ → 機能拡張（Extensions） → Clip-Adjust**

こんな感じのパネルが出てきます（好きな場所にドッキングできます）：

```
┌─ Clip-Adjust ───────────────┐
│  テロップ同期                │
├──────────────────────────────┤
│  ベース動画トラック          │
│  [ V1  (23 本) ▼ ]           │
│                              │
│  テロップトラック            │
│  [ V2  (23 本) ▼ ]           │
│                              │
│  許容フレーム数              │
│  [ 5 ]  （1〜120）           │
│                              │
│  [ 更新 ]        [  実行  ]  │
├──────────────────────────────┤
│  シーケンス: MyEdit01        │
│  「実行」を押してください    │
└──────────────────────────────┘                  v1.0.0
```

## ステップ 3. 3 つ選んで「実行」を押す

| 項目 | 説明 |
|---|---|
| **ベース動画トラック** | タイミングの**基準にしたい**動画があるトラック。普通は動画の本体を置いている `V1` |
| **テロップトラック** | **動かしたい**テロップがあるトラック。`V2` など |
| **許容フレーム数** | 「どれくらいズレていたら合わせてくれるか」の数字。**5 がおすすめ**。<br>数字が大きいほど、遠くのテロップも無理やり引き寄せます（注意） |

確認ダイアログが出ます：

```
対象テロップ: 23 本
スナップ対象: 19 本
スキップ:      4 本（許容範囲外 or 既に一致）

この内容で実行しますか？
```

「OK」を押すと数秒で完了。タイムライン上のテロップの頭が、カットの切り替わりにピタッとそろいます。

## 結果が気に入らなかったら？

**Cmd + Z**（Mac）/ **Ctrl + Z**（Windows）で、いつも通り元に戻せます。

---

## ちょっとしたコツ

- **許容フレーム数は、最初は 5 で試すのがおすすめ。**
  うまく合わなかったテロップが多いなら、10 や 15 に増やしてもう一度実行。
- **反対に、合ってほしくないテロップまで動いてしまう** なら、3 や 2 に減らしてください。
- **このツールはテロップの「長さ」は変えません。**位置だけをそっと横にずらします。
- 実行前にプロジェクトを **別名保存** しておくと、万が一のときに安心です。
- トラックを増減したりシーケンスを切り替えたりしたら、パネル上の **「更新」ボタン** を押してトラック一覧を読み直してください。

## よくある質問

**Q. ZXPInstaller で「この拡張機能は署名されていますが、開発元が確認できません」のような警告が出ます。**
A. 自己署名証明書で署名しているためです。**そのまま「Install」を押して進めて大丈夫**です（悪意あるコードが含まれていないかは GitHub のソースコードで確認できます）。

**Q. ウィンドウメニューに「機能拡張」が見当たりません。**
A. Premiere Pro 2024 以降を使っていることを確認してください。2023 以前は CEP 拡張機能のバージョンが異なり、動作しません。

**Q. 機能拡張メニューに「Clip-Adjust」が出てきません。**
A. Premiere Pro を一度完全に終了して、もう一度起動してください。それでも出ない場合は、ZXPInstaller のインストールが途中で失敗している可能性があります。もう一度 `.zxp` をドラッグ＆ドロップしてみてください。

**Q. 「ビデオトラックが見つかりません」と出ます。**
A. シーケンスを開いていない可能性があります。プロジェクトで編集中のシーケンスを開いてから、パネルの「更新」ボタンを押してください。

**Q. テロップが勝手におかしな位置に飛んでしまいました。**
A. **Cmd + Z**（Mac）/ **Ctrl + Z**（Windows）で戻せます。許容フレーム数を小さくして試してみてください。

**Q. 音声（しゃべり始め）に合わせることはできますか？**
A. 今のバージョン（v1）では、**カットの切り替わり**に合わせるだけです。「しゃべり始めのタイミング」に合わせる機能は、将来のバージョンで追加予定です。

**Q. アンインストールはどうすればいいですか？**
A. ZXPInstaller アプリ内に「Installed Extensions」の一覧があり、そこから削除できます。

## 開発者向け

ローカルで `.zxp` をビルドしたい場合：

```bash
# Mac / Linux
./build/build.sh

# Windows
powershell -ExecutionPolicy Bypass -File build\build.ps1
```

`dist/Clip-Adjust-vX.Y.Z.zxp` が生成されます。初回実行時に Adobe の ZXPSignCmd と自己署名証明書が自動で準備されます。

GitHub に `vX.Y.Z` タグを push すると、GitHub Actions が自動でビルドして Release に `.zxp` を添付します。

詳しい仕様は [`docs/requirements.md`](docs/requirements.md) を参照。
