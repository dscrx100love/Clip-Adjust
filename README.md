# Clip-Adjust

**Premiere Pro で、動画のカットとテロップのタイミングが微妙にズレる問題を、ワンクリックでまとめて直すツール。**

Mac・Windows どちらでも使えます。ファイルを 1 つコピーするだけで導入できます。

---

## こんな悩みありませんか？

動画編集をしていて、こんな経験ありませんか？

- トーク動画を**カット編集したあと**、別トラックに**テロップを並べた**
- でも、カットした瞬間とテロップが出るタイミングが **数フレームだけズレている**
- テロップ 1 本ずつ手で「あと 2 フレームだけ右へ…」と直すのが地獄

**Clip-Adjust はこれを一瞬で直します。**

> ベースの動画クリップが「切り替わる瞬間」に、テロップを **自動でピタッと寄せる**。
> そういうツールです。

---

## こんな動きをします

たとえば、**V1 に動画**、**V2 にテロップ**を置いたタイムラインがあるとします。

```
 時間 →
V1  [動画カット①][動画カット②][動画カット③]
V2      [テロップA]    [テロップB]    [テロップC]
           ↑3F遅い      ↑2F早い       ↑ぴったり
```

このツールを実行すると：

```
V1  [動画カット①][動画カット②][動画カット③]
V2  [テロップA]  [テロップB]    [テロップC]
     ↑合った     ↑合った         ↑そのまま
```

こんな風に、**カットの切り替わりにテロップの頭をそろえてくれます。**

もし「許容フレーム」で決めた数字より大きくズレているテロップは、**安全のため触りません**（勝手に遠くへ飛ばされないように）。

## 動作環境

- **Adobe Premiere Pro 2024 以降**（2023 以前は対応外）
- **Mac**: macOS 12（Monterey）以降
- **Windows**: Windows 10 または 11

## 導入（はじめて使う場合）

やることは 2 つだけです：

1. `SubtitleSync.jsx` を **ダウンロード**する
2. Premiere Pro の所定のフォルダに **コピー**する

「所定のフォルダ」がどこにあるか、OS ごとに順を追って説明します。

### ステップ 1. ファイルをダウンロード

このページ上部の **`SubtitleSync.jsx`** をクリック → 右上の **「Download raw file」**（↓のアイコン）を押して保存してください。

> または、緑の「Code」ボタン →「Download ZIP」でまとめてダウンロードして、中の `SubtitleSync.jsx` を取り出してもOKです。

---

### ステップ 2-A. Mac の場合

1. **Finder を開く**

2. 画面上部のメニューから **「移動」→「フォルダへ移動...」** を選ぶ
   （ショートカット: `Cmd + Shift + G`）

3. 出てきた入力欄に下の文字をコピペして Enter：

   ```
   ~/Documents/Adobe/Premiere Pro
   ```

4. フォルダの中に **`24.0`** や **`25.0`** のような **バージョン番号のフォルダ**があります。
   一番大きい数字のフォルダを開いてください（= 一番新しい Premiere Pro）。

5. その中に **`Scripts`** という名前のフォルダがあれば、それを開きます。
   **なければ**、新しく「Scripts」という名前のフォルダを作ってください。

6. ステップ 1 でダウンロードした **`SubtitleSync.jsx` を、この Scripts フォルダに入れます**（ドラッグ＆ドロップでOK）。

7. 完了！ Premiere Pro を再起動すれば、メニューに出てきます。

---

### ステップ 2-B. Windows の場合

1. **エクスプローラー**（ファイルを見るいつものウィンドウ）を開く

2. 画面上のアドレスバー（`PC > ドキュメント` のように表示されている部分）を**クリック**して、下の文字をコピペして Enter：

   ```
   %USERPROFILE%\Documents\Adobe\Premiere Pro
   ```

3. フォルダの中に **`24.0`** や **`25.0`** のような **バージョン番号のフォルダ**があります。
   一番大きい数字のフォルダを開いてください（= 一番新しい Premiere Pro）。

4. その中に **`Scripts`** という名前のフォルダがあれば、それを開きます。
   **なければ**、新しく「Scripts」という名前のフォルダを作ってください。

5. ステップ 1 でダウンロードした **`SubtitleSync.jsx` を、この Scripts フォルダに入れます**（ドラッグ＆ドロップでOK）。

6. 完了！ Premiere Pro を再起動すれば、メニューに出てきます。

---

### ステップ 3. Premiere Pro を再起動

すでに開いている場合は、一度閉じてから開き直してください。

### ステップ 4. 準備完了！

Premiere Pro のメニューから：

**ファイル → スクリプト → SubtitleSync**

が選べるようになっていれば、導入成功です。

> **メニューに出てこない場合**: Premiere Pro を **一度でも起動したこと** がないと、`Documents/Adobe/Premiere Pro/<バージョン>` のフォルダ自体が作られていません。まず Premiere を起動して、プロジェクトを 1 つ作ってから、もう一度ステップ 2 を試してください。

---

## 毎回コピーせずに「今すぐ 1 回だけ試したい」人向け

インストールせずに試す方法もあります：

1. `SubtitleSync.jsx` を **好きな場所**（デスクトップなど）に保存
2. Premiere Pro で **ファイル → スクリプト → スクリプトファイルを実行...** を選ぶ
3. さっき保存した `SubtitleSync.jsx` を選んで「開く」

これで 1 回だけ実行できます。気に入ったら、上の「導入」手順で正式に入れてください。

## 使い方（実際にテロップを合わせてみる）

### 1. 編集中のシーケンスを開く

ベースとなる動画クリップとテロップが **別々のトラック** に置かれていることを確認してください。
（例: 動画が V1、テロップが V2 にある状態）

### 2. ツールを起動

Premiere Pro のメニュー：
**ファイル → スクリプト → SubtitleSync**

こんなウィンドウが出てきます：

```
┌─ Clip-Adjust / テロップ同期 ────────────┐
│                                          │
│  ベース動画トラック:  [ V1        ▼ ]    │
│  テロップトラック:    [ V2        ▼ ]    │
│  許容フレーム数:      [  5  ] （1〜120）  │
│                                          │
│  [✓] 処理前にプレビュー（件数のみ）      │
│                                          │
│           [キャンセル]  [実行]           │
└──────────────────────────────────────────┘
```

### 3. 3 つを選ぶだけ

| 項目 | 説明 |
|---|---|
| **ベース動画トラック** | タイミングの**基準にしたい**動画があるトラック。普通は動画の本体を置いている `V1` |
| **テロップトラック** | **動かしたい**テロップがあるトラック。`V2` など |
| **許容フレーム数** | 「どれくらいズレていたら合わせてくれるか」の数字。**5 がおすすめ**。<br>数字が大きいほど、遠くのテロップも無理やり引き寄せます（注意） |

### 4. 「実行」を押す

確認画面が出ます：

```
対象テロップ数: 23 本
スナップ対象:   19 本
スキップ:        4 本（ズレが大きすぎて触らない）

実行しますか？
```

「はい」で確定。数秒で完了します。

### 5. 結果を確認

```
完了しました。

  スナップ済み: 19 本
  スキップ:      4 本
  合計:         23 本
```

タイムラインを見ると、テロップの頭がカットとピッタリそろっているはずです。

### もし結果が気に入らなかったら？

**Cmd + Z**（Mac）/ **Ctrl + Z**（Windows）で、いつも通り元に戻せます。

## ちょっとしたコツ

- **許容フレーム数は、最初は 5 で試すのがおすすめ。**
  うまく合わなかったテロップが多いなら、10 や 15 に増やしてもう一度実行。
- **反対に、合ってほしくないテロップまで動いてしまう** なら、3 や 2 に減らしてください。
- **このツールはテロップの「長さ」は変えません。**位置だけをそっと横にずらします。
- 実行前にプロジェクトを **別名保存** しておくと、万が一のときに安心です。

## よくある質問

**Q. メニューに「SubtitleSync」が出てきません。**
A. 考えられる原因は 3 つです：
  1. Premiere Pro を再起動していない → 一度完全に閉じて開き直してください
  2. コピー先のフォルダを間違えている → バージョン番号のフォルダ（例: `25.0`）の中の `Scripts` に入れたか確認
  3. Premiere Pro をまだ一度も起動していない → 一度 Premiere を起動してから、もう一度コピーを試してください

**Q. 「Scripts」フォルダが見つかりません。**
A. バージョン番号のフォルダ（例: `25.0`）の中に「Scripts」が無い場合は、**自分で新しく作ってください**。名前は半角英字で `Scripts`（S は大文字）にしてください。

**Q. 「テロップトラックにクリップがありません」と出ます。**
A. ベーストラックとテロップトラックを選び間違えている可能性があります。トラック番号を確認してください。

**Q. テロップが勝手におかしな位置に飛んでしまいました。**
A. **Cmd + Z**（Mac）/ **Ctrl + Z**（Windows）で戻せます。許容フレーム数を小さくして試してみてください。

**Q. 音声（しゃべり始め）に合わせることはできますか？**
A. 今のバージョン（v1）では、**カットの切り替わり**に合わせるだけです。「しゃべり始めのタイミング」に合わせる機能は、将来のバージョンで追加予定です。
