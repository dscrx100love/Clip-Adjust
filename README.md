# Clip-Adjust

Premiere Pro 用のテロップ同期ツール。
ベース動画のカット開始位置にテロップの IN 点を一括で吸着させる ExtendScript。

![platform](https://img.shields.io/badge/platform-macOS%20%7C%20Windows-lightgrey) ![premiere](https://img.shields.io/badge/Premiere%20Pro-2024%2B-blueviolet)

## 何をするツール？

- ベースとなる動画トラック（例: V1 のトーク素材）を基準に、
- テロップトラック（例: V2 のグラフィック）の各クリップを、
- 許容フレーム数（既定: 5F）以内なら **最寄りのベース IN 点にスナップ** します。
- 許容を超えた大きなズレは誤吸着を避けて **スキップ**、元位置のまま。
- IN / OUT を同量スライドするため、テロップの **尺（長さ）は変わりません**。

手作業で 1 本ずつ微調整していたフレーム単位のズレを、1 アクションで解消するのが目的です。

## 動作環境

- Adobe Premiere Pro **2024 (v24) 以降**
- macOS 12 (Monterey) 以降 / Windows 10・11

## インストール

### 方法 A: ワンクリックインストーラー（推奨）

1. [Releases](../../releases) から最新の zip をダウンロードして解凍
2. OS に合わせてダブルクリック
    - **macOS:** `install-mac.command`
    - **Windows:** `install-win.bat`
3. Premiere Pro を **再起動**
4. **ファイル > スクリプト > SubtitleSync** から起動可能に

> macOS で「開発元を確認できないため開けません」と出た場合:
> Finder で右クリック → 「開く」を選ぶと一度だけ警告が出て、以降は普通にダブルクリックで動きます。

### 方法 B: インストールせずにお試し

1. zip を解凍して `SubtitleSync.jsx` を任意の場所に配置
2. Premiere Pro で **ファイル > スクリプト > スクリプトファイルを実行...** → `.jsx` を選択

## 使い方

1. プロジェクトと対象シーケンスを開いた状態で、**ファイル > スクリプト > SubtitleSync** を実行
2. ダイアログで 3 つを指定:
    - **ベース動画トラック**（例: V1）
    - **テロップトラック**（例: V2）
    - **許容フレーム数**（既定 5、1〜120）
3. 「実行」→ プレビュー → 確定

処理後は Premiere 標準の **Cmd/Ctrl + Z** で元に戻せます。

## 仕様の詳細

- [`docs/requirements.md`](docs/requirements.md) に要件定義書があります。
- スナップの方向: ベースクリップの **IN 点**（= カット頭）に最寄り
- スナップの移動量: `Δ = 最寄りベース IN − テロップ現 IN`、|Δ| ≦ 許容 なら適用
- 等距離の場合: より後ろのベース IN を採用
- 尺は維持（IN / OUT を同量だけ平行移動 = スライド）

## 既知の制約

- v1 は音声解析による「実際の発話開始点」検出は非対応（将来拡張予定）
- 対象は **アクティブな 1 シーケンス**、ビデオトラックのみ
- 処理中に他クリップと重なる可能性がある場合、Premiere 側のデフォルト挙動に従います
