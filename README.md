# Clip-Adjust

**Premiere Pro で、動画のカットとテロップのタイミングが微妙にズレる問題を、ワンクリックでまとめて直すツール。**

Mac・Windows どちらでも使えます。ダウンロードしてダブルクリックするだけで導入できます。

---

## こんな悩みありませんか？

動画編集をしていて、こんな経験ありませんか？

- トーク動画を**カット編集したあと**、別トラックに**テロップを並べた**
- でも、カットした瞬間とテロップが出るタイミングが **数フレームだけズレている**
- テロップ 1 本ずつ手で「あと 2 フレームだけ右へ…」と直すのが地獄

**Clip-Adjust はこれを一瞬で直します。**

> ベースの動画クリップが「切り替わる瞬間」に、テロップを **自動でピタッと寄せる**。
> そういうツールです。

---

## こんな動きをします

たとえば、**V1 に動画**、**V2 にテロップ**を置いたタイムラインがあるとします。

```
 時間 →
V1  [動画カット①][動画カット②][動画カット③]
V2      [テロップA]    [テロップB]    [テロップC]
           ↑3F遅い      ↑2F早い       ↑ぴったり
```

このツールを実行すると：

```
V1  [動画カット①][動画カット②][動画カット③]
V2  [テロップA]  [テロップB]    [テロップC]
     ↑合った     ↑合った         ↑そのまま
```

こんな風に、**カットの切り替わりにテロップの頭をそろえてくれます。**

もし「許容フレーム」で決めた数字より大きくズレているテロップは、**安全のため触りません**（勝手に遠くへ飛ばされないように）。

## 動作環境

- **Adobe Premiere Pro 2024 以降**（2023 以前は対応外）
- **Mac**: macOS 12（Monterey）以降
- **Windows**: Windows 10 または 11

## 導入（はじめて使う場合）

### ステップ 1. ダウンロード

このページ右側の **「Releases」** から最新版の zip ファイルをダウンロードしてください。
（または緑の「Code」ボタン →「Download ZIP」でも OK）

### ステップ 2. zip を解凍

ダウンロードした zip ファイルをダブルクリックすると、中にこんなファイルが入っています：

```
SubtitleSync.jsx        ← 本体
install-mac.command     ← Mac 用のインストーラー
install-win.bat         ← Windows 用のインストーラー
README.md               ← この説明書
```

### ステップ 3. インストーラーをダブルクリック

**Mac の人:**
- `install-mac.command` をダブルクリック
- もし「開発元を確認できないため開けません」と出たら：
  1. ファイルを **右クリック**（または Control キーを押しながらクリック）
  2. メニューから **「開く」** を選ぶ
  3. もう一度確認が出るので **「開く」**
  4. 次回からは普通にダブルクリックで OK

**Windows の人:**
- `install-win.bat` をダブルクリック
- もし「WindowsによってPCが保護されました」と出たら：
  1. **「詳細情報」** をクリック
  2. **「実行」** ボタンを押す

黒い画面が開いて「完了しました」と出れば成功です。Enter キーで閉じてください。

### ステップ 4. Premiere Pro を再起動

すでに Premiere Pro を開いている場合は、一度閉じてから開き直してください。

### ステップ 5. 準備完了！

Premiere Pro のメニューから：

**ファイル → スクリプト → SubtitleSync**

が選べるようになっていれば、導入成功です。

## 使い方（実際にテロップを合わせてみる）

### 1. 編集中のシーケンスを開く

ベースとなる動画クリップとテロップが **別々のトラック** に置かれていることを確認してください。
（例: 動画が V1、テロップが V2 にある状態）

### 2. ツールを起動

Premiere Pro のメニュー：
**ファイル → スクリプト → SubtitleSync**

こんなウィンドウが出てきます：

```
┌─ Clip-Adjust / テロップ同期 ────────────┐
│                                          │
│  ベース動画トラック:  [ V1        ▼ ]    │
│  テロップトラック:    [ V2        ▼ ]    │
│  許容フレーム数:      [  5  ] （1〜120）  │
│                                          │
│  [✓] 処理前にプレビュー（件数のみ）      │
│                                          │
│           [キャンセル]  [実行]           │
└──────────────────────────────────────────┘
```

### 3. 3 つを選ぶだけ

| 項目 | 説明 |
|---|---|
| **ベース動画トラック** | タイミングの**基準にしたい**動画があるトラック。普通は動画の本体を置いている `V1` |
| **テロップトラック** | **動かしたい**テロップがあるトラック。`V2` など |
| **許容フレーム数** | 「どれくらいズレていたら合わせてくれるか」の数字。**5 がおすすめ**。<br>数字が大きいほど、遠くのテロップも無理やり引き寄せます（注意） |

### 4. 「実行」を押す

ONにしている場合、確認画面が出ます：

```
対象テロップ数: 23 本
スナップ対象:   19 本
スキップ:        4 本（ズレが大きすぎて触らない）

実行しますか？
```

「はい」で確定。数秒で完了します。

### 5. 結果を確認

```
完了しました。

  スナップ済み: 19 本
  スキップ:      4 本
  合計:         23 本
```

タイムラインを見ると、テロップの頭がカットとピッタリそろっているはずです。

### もし結果が気に入らなかったら？

**Cmd + Z**（Mac）/ **Ctrl + Z**（Windows）で、いつも通り元に戻せます。

## ちょっとしたコツ

- **許容フレーム数は、最初は 5 で試すのがおすすめ。**
  うまく合わなかったテロップが多いなら、10 や 15 に増やしてもう一度実行。
- **反対に、合ってほしくないテロップまで動いてしまう** なら、3 や 2 に減らしてください。
- **このツールはテロップの「長さ」は変えません。**位置だけをそっと横にずらします。
- 実行前にプロジェクトを **別名保存** しておくと、万が一のときに安心です。

## よくある質問

**Q. インストーラーを実行したのに、メニューに出てきません。**
A. Premiere Pro を一度完全に閉じて、もう一度開いてください。それでも出ない場合は、Premiere Pro を一度起動して何か編集してから、もう一度インストーラーを実行してください（Premiere の設定フォルダが作られていないことがあります）。

**Q. 「テロップトラックにクリップがありません」と出ます。**
A. ベーストラックとテロップトラックを選び間違えている可能性があります。トラック番号を確認してください。

**Q. テロップが勝手におかしな位置に飛んでしまいました。**
A. **Cmd + Z**（Mac）/ **Ctrl + Z**（Windows）で戻せます。許容フレーム数を小さくして試してみてください。

**Q. 音声（しゃべり始め）に合わせることはできますか？**
A. 今のバージョン（v1）では、**カットの切り替わり**に合わせるだけです。「しゃべり始めのタイミング」に合わせる機能は、将来のバージョンで追加予定です。

**Q. インストールせずに試したいです。**
A. `SubtitleSync.jsx` を好きな場所に置いて、Premiere Pro で **ファイル → スクリプト → スクリプトファイルを実行...** からそのファイルを選べば、インストールなしで使えます。
