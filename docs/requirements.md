# Clip-Adjust 要件定義書

Premiere Pro 上でベース動画クリップのカット開始位置にテロップのIN点を吸着させる ExtendScript ツール。

---

## 1. 目的

編集済みのベース動画（カット済みトーク素材など）に対して、あとから載せたテロップ群の
タイミングがフレーム単位で微妙にズレている状況を、**ワンクリックで一括補正する**こと。

- 手作業でテロップを 1 本ずつスナップする手間をなくす
- 許容範囲を超えた大きなズレは誤補正を避けるためスキップする（安全側に倒す）
- Mac / Windows どちらの Premiere Pro でも同じ .jsx が動く

## 2. スコープ

### 2.1 対象ユーザー
- Premiere Pro で会話系動画（Vlog / インタビュー / 実況 等）を編集する個人編集者
- ある程度テロップ配置を手動で行っており、カット点とのズレが気になる人

### 2.2 対象 Premiere Pro バージョン
- **Premiere Pro 2024 (v24.x) 以降** を下限動作保証
- 2023 以前での動作は best-effort（動けばラッキー扱い、サポート外）

### 2.3 対象 OS
- macOS 12 (Monterey) 以降
- Windows 10 / 11

### 2.4 非対象（やらないこと）
- v1 では音声解析による「実際の発話開始位置」検出は **行わない**（クリップ境界ベースのみ）
- 複数シーケンス横断での一括処理は行わない（アクティブなシーケンス 1 本が対象）
- テロップの文字内容の書き換え・生成は行わない
- OUT 点の自動調整は行わない（IN 点のみ移動）

## 3. 前提条件

- Premiere Pro のプロジェクトが開かれており、少なくとも 1 本のシーケンスがアクティブ
- ベース動画トラックとテロップトラックが **別トラック** に分かれている
- テロップは「グラフィッククリップ」「テキストクリップ」「プリコンポーズされた動画クリップ」のいずれでも可（トラック上にクリップとして存在していれば対象）

## 4. 用語定義

| 用語 | 定義 |
|---|---|
| ベースクリップ | 位置の基準となる動画クリップ。通常はカット済みのトーク素材 |
| テロップクリップ | 位置を動かされる側のクリップ。字幕・テロップ・グラフィックなど |
| IN 点 | クリップのタイムライン上の開始位置（= Start Time） |
| 許容フレーム | IN 点同士の差がこのフレーム数以内であればスナップする閾値 |
| スナップ | テロップクリップを「スライド」させて、IN 点を目的位置に一致させる操作（OUT 点は同量平行移動 → 尺は維持） |

> **補足:** 当初「IN 点だけ動かす」仕様を検討したが、テロップは連続配置される性質上、
> クリップ全体をスライドさせて尺を維持する方が自然なため、**内部的には "スライド"**
> （IN / OUT を同量ずつ平行移動）として実装する。ユーザーからは「IN 位置が合う」挙動に見える。

## 5. 機能要件

### 5.1 起動
- Premiere Pro の **ファイル > スクリプト > SubtitleSync** から起動（インストール済みの場合）
- もしくは **ファイル > スクリプト > スクリプトファイルを実行...** で `.jsx` を指定して起動（インストール不要モード）

### 5.2 UI（ScriptUI ダイアログ）

起動するとモーダルダイアログが表示される。構成：

```
┌─ Clip-Adjust / テロップ同期 ────────────────┐
│                                              │
│  ベース動画トラック:    [ V1         ▼ ]     │
│  テロップトラック:      [ V2         ▼ ]     │
│  許容フレーム数:        [   5        ]       │
│                                              │
│  [✓] 処理前にプレビュー（件数のみ）          │
│                                              │
│          [ キャンセル ]   [ 実行 ]           │
└──────────────────────────────────────────────┘
```

#### 5.2.1 入力フィールド仕様

| 項目 | 型 | 既定値 | 制約 |
|---|---|---|---|
| ベース動画トラック | ドロップダウン | V1 | アクティブシーケンスに存在するビデオトラック一覧 |
| テロップトラック | ドロップダウン | V2 | 同上、ベースと同一トラックは選択不可（エラー表示） |
| 許容フレーム数 | 整数入力 | 5 | 1〜120 の範囲、範囲外はエラー |
| プレビュー | チェックボックス | ON | ON の場合、実行前に件数確認ダイアログを挟む |

#### 5.2.2 プレビューダイアログ（オプション）
「実行」押下時、プレビューが ON なら次のサマリーを表示してから確定：

```
対象テロップ数:     23 本
スナップ対象:       19 本（差分が許容範囲内）
スキップ:            4 本（差分が許容範囲外）

           [ 戻る ]   [ 実行する ]
```

### 5.3 コアロジック（スナップ処理）

1. アクティブシーケンスからフレームレートを取得（drop-frame / non-drop 両対応）
2. 指定されたベーストラックの全クリップの **IN 点タイムコード配列** を取得
3. 指定されたテロップトラックの全クリップを走査
4. 各テロップクリップについて：
    1. 現在の IN 点を取得
    2. ベース IN 点配列から **最も近い** IN 点を 1 つ選ぶ
    3. 差分（絶対値）を算出
    4. 差分 ≦ 許容フレーム数 の場合：
       - テロップクリップを「最寄りベース IN 点 − 現在 IN 点」だけ **スライド** する
       - （= clip.start と clip.end を同じデルタだけ加算、尺は変わらない）
    5. 差分 > 許容フレーム数 の場合：
       - 何もしない（スキップ）
5. 処理結果を undo スタックに 1 ステップで収める（Premiere の Cmd/Ctrl+Z で全部戻せる）

#### 5.3.1 エッジケース方針

| ケース | 挙動 |
|---|---|
| ベーストラックにクリップが 0 本 | エラー表示して中止 |
| テロップトラックにクリップが 0 本 | 情報表示して終了（エラーではない） |
| 複数ベース IN が等距離にある | より後ろの IN を採用 |
| スライド後に他クリップと重なる | そのままスライドする（Premiere 側のデフォルト挙動に任せる） |
| ロック中のトラック | エラー表示して中止 |
| タイムラインにイン／アウト範囲設定あり | 無視（シーケンス全体を対象） |

### 5.4 結果レポート

処理後、次のサマリーをダイアログ表示：

```
完了しました。

  スナップ済み:  19 本
  スキップ:       4 本（許容範囲外）
  合計:          23 本

                          [ OK ]
```

### 5.5 Undo
- 1 回の実行が Premiere の履歴 1 ステップになること（`app.enableQE()` や履歴 API 併用）
- ユーザーが Cmd/Ctrl+Z を押したら、全テロップが元の位置に戻ること

## 6. 非機能要件

| 項目 | 要件 |
|---|---|
| パフォーマンス | テロップ 500 本規模で実行時間 5 秒以内 |
| 依存 | 外部ライブラリなし（素の ExtendScript + ScriptUI のみ） |
| ファイル数 | メインスクリプトは単一 `.jsx` ファイル（配布容易性のため） |
| エラー | 致命的エラーは日本語でダイアログ表示、処理は必ずロールバック |
| ログ | 処理詳細はコンソール（ExtendScript Toolkit / VSCode Debugger）に出力 |
| i18n | UI 文言は日本語のみ（v1） |

## 7. 配布・インストール方式

### 7.1 配布物
```
SubtitleSync.jsx          ← 本体（単一ファイル、これだけで完結）
README.md                 ← 導入・使い方
docs/requirements.md      ← 本ドキュメント
LICENSE
```

### 7.2 導入パターン

> **方針:** バイナリ配布（.command / .bat 等の実行ファイル）は macOS の Gatekeeper や
> Windows SmartScreen の警告でかえって導入ハードルが上がるため **採用しない**。
> 手動コピー（= OS のファイル操作のみ）をメインにする。

#### パターン A: 手動コピー（推奨）
1. `SubtitleSync.jsx` を取得（Releases or raw ダウンロード）
2. OS 別に所定のユーザー Scripts フォルダへコピー
    - **macOS:** `~/Documents/Adobe/Premiere Pro/<version>/Scripts/`
    - **Windows:** `%USERPROFILE%\Documents\Adobe\Premiere Pro\<version>\Scripts\`
3. `Scripts` フォルダが存在しない場合はユーザーが新規作成（README で明記）
4. Premiere Pro を再起動 → **ファイル > スクリプト > SubtitleSync** から起動可能

#### パターン B: インストールせずに毎回実行
1. `SubtitleSync.jsx` を任意の場所に保存
2. Premiere Pro で **ファイル > スクリプト > スクリプトファイルを実行...** から選択

### 7.3 README 記述要件

- 「所定のフォルダへコピー」の手順を OS 別にスクリーンショット代わりのテキスト指示で説明
- Mac: Finder の「フォルダへ移動」（`Cmd+Shift+G`）でパスを貼り付ける前提
- Windows: エクスプローラーのアドレスバーにパスを貼り付ける前提
- バージョンフォルダ（例: `25.0`）が複数ある場合は「一番新しいもの」を開くよう指示
- `Scripts` フォルダが無い場合の新規作成を明示

## 9. 将来拡張（v1 非対応 / v2 以降の検討事項）

| 機能 | 優先度 |
|---|---|
| 音声解析による「発話開始点」スナップ（VAD + ffmpeg 同梱） | 高 |
| 複数テロップトラックの一括処理 | 中 |
| OUT 点も吸着するモード | 中 |
| タイムライン選択範囲のみを対象にする | 中 |
| 英語 UI | 低 |
| CEP パネル版（ドック可能 UI） | 低 |
| スナップ先をベース IN だけでなく OUT にも拡張 | 低 |

## 10. 受け入れ基準（v1 完了条件）

以下すべてを満たすこと：

- [ ] Mac / Windows の Premiere Pro 2024 以降で `.jsx` がクラッシュせず起動する
- [ ] UI で 2 つのトラックと許容フレームを指定して実行できる
- [ ] 許容範囲内のテロップのみがスナップされ、範囲外はスキップされる
- [ ] 尺が意図せず変わらない（スライド動作で IN/OUT が同量移動）
- [ ] Cmd/Ctrl+Z で一括 undo できる
- [ ] README の手順（手動コピー）だけで非エンジニアが導入・実行できる
- [ ] 導入フローに OS のセキュリティ警告（Gatekeeper / SmartScreen）を踏まない
