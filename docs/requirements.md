# Clip-Adjust 要件定義書

Premiere Pro 上でベース動画クリップのカット開始位置にテロップのIN点を吸着させる **CEP 拡張パネル**。

---

## 1. 目的

編集済みのベース動画（カット済みトーク素材など）に対して、あとから載せたテロップ群の
タイミングがフレーム単位で微妙にズレている状況を、**ワンクリックで一括補正する**こと。

- 手作業でテロップを 1 本ずつスナップする手間をなくす
- 許容範囲を超えた大きなズレは誤補正を避けるためスキップする（安全側に倒す）
- Mac / Windows どちらの Premiere Pro でも同じパネルが動く

## 2. スコープ

### 2.1 対象ユーザー
- Premiere Pro で会話系動画（Vlog / インタビュー / 実況 等）を編集する個人編集者
- ある程度テロップ配置を手動で行っており、カット点とのズレが気になる人

### 2.2 対象 Premiere Pro バージョン
- **Premiere Pro 2024 (v24.x) 以降** を下限動作保証
- 2023 以前での動作は best-effort（動けばラッキー扱い、サポート外）

### 2.3 対象 OS
- macOS 12 (Monterey) 以降
- Windows 10 / 11

### 2.4 非対象（やらないこと）
- v1 では音声解析による「実際の発話開始位置」検出は **行わない**（クリップ境界ベースのみ）
- 複数シーケンス横断での一括処理は行わない（アクティブなシーケンス 1 本が対象）
- テロップの文字内容の書き換え・生成は行わない
- OUT 点の自動調整は行わない（IN 点のみ移動）

## 3. 前提条件

- Premiere Pro のプロジェクトが開かれており、少なくとも 1 本のシーケンスがアクティブ
- ベース動画トラックとテロップトラックが **別トラック** に分かれている
- テロップは「グラフィッククリップ」「テキストクリップ」「プリコンポーズされた動画クリップ」のいずれでも可（トラック上にクリップとして存在していれば対象）

## 4. 用語定義

| 用語 | 定義 |
|---|---|
| ベースクリップ | 位置の基準となる動画クリップ。通常はカット済みのトーク素材 |
| テロップクリップ | 位置を動かされる側のクリップ。字幕・テロップ・グラフィックなど |
| IN 点 | クリップのタイムライン上の開始位置（= Start Time） |
| 許容フレーム | IN 点同士の差がこのフレーム数以内であればスナップする閾値 |
| スナップ | テロップクリップを「スライド」させて、IN 点を目的位置に一致させる操作（OUT 点は同量平行移動 → 尺は維持） |

> **補足:** 当初「IN 点だけ動かす」仕様を検討したが、テロップは連続配置される性質上、
> クリップ全体をスライドさせて尺を維持する方が自然なため、**内部的には "スライド"**
> （IN / OUT を同量ずつ平行移動）として実装する。ユーザーからは「IN 位置が合う」挙動に見える。

## 5. 機能要件

### 5.1 起動
- Premiere Pro の **ウィンドウ > 機能拡張（Extensions） > Clip-Adjust** からパネルを開く
- 一度開けばパネルとしてドッキング可能、常駐利用できる
- パネル形式のため、モーダルダイアログではなく **非モーダル** の UI として動作

### 5.2 UI（HTML パネル）

Premiere Pro の拡張パネルとして HTML/CSS/JS で構築。構成：

```
┌─ Clip-Adjust ─────────────────────┐
│  テロップ同期                      │
├────────────────────────────────────┤
│  ベース動画トラック                │
│  [ V1  (23 本) ▼ ]                 │
│                                    │
│  テロップトラック                  │
│  [ V2  (23 本) ▼ ]                 │
│                                    │
│  許容フレーム数                    │
│  [ 5 ]  （1〜120）                 │
│                                    │
│  [ 更新 ]          [  実行  ]      │
├────────────────────────────────────┤
│  ステータス表示エリア              │
│  （処理進捗・結果を表示）          │
└────────────────────────────────────┘ v1.0.0
```

- トラック一覧は起動時に自動取得。シーケンス切り替え時は **「更新」ボタン** で再取得
- 「実行」押下時は confirm ダイアログで件数サマリーを提示してから確定
- 処理結果はパネル内のステータス領域に表示（OK / エラー / 警告の色分け）

#### 5.2.1 入力フィールド仕様

| 項目 | 型 | 既定値 | 制約 |
|---|---|---|---|
| ベース動画トラック | ドロップダウン | V1 | アクティブシーケンスに存在するビデオトラック一覧 |
| テロップトラック | ドロップダウン | V2 | 同上、ベースと同一トラックは選択不可（エラー表示） |
| 許容フレーム数 | 整数入力 | 5 | 1〜120 の範囲、範囲外はエラー |

#### 5.2.2 確認ダイアログ
「実行」押下時、まず件数サマリーを提示してから確定する（ネイティブ confirm）：

```
対象テロップ数:     23 本
スナップ対象:       19 本（差分が許容範囲内）
スキップ:            4 本（差分が許容範囲外）

           [ 戻る ]   [ 実行する ]
```

### 5.3 コアロジック（スナップ処理）

1. アクティブシーケンスからフレームレートを取得（drop-frame / non-drop 両対応）
2. 指定されたベーストラックの全クリップの **IN 点タイムコード配列** を取得
3. 指定されたテロップトラックの全クリップを走査
4. 各テロップクリップについて：
    1. 現在の IN 点を取得
    2. ベース IN 点配列から **最も近い** IN 点を 1 つ選ぶ
    3. 差分（絶対値）を算出
    4. 差分 ≦ 許容フレーム数 の場合：
       - テロップクリップを「最寄りベース IN 点 − 現在 IN 点」だけ **スライド** する
       - （= clip.start と clip.end を同じデルタだけ加算、尺は変わらない）
    5. 差分 > 許容フレーム数 の場合：
       - 何もしない（スキップ）
5. 処理結果を undo スタックに 1 ステップで収める（Premiere の Cmd/Ctrl+Z で全部戻せる）

#### 5.3.1 エッジケース方針

| ケース | 挙動 |
|---|---|
| ベーストラックにクリップが 0 本 | エラー表示して中止 |
| テロップトラックにクリップが 0 本 | 情報表示して終了（エラーではない） |
| 複数ベース IN が等距離にある | より後ろの IN を採用 |
| スライド後に他クリップと重なる | そのままスライドする（Premiere 側のデフォルト挙動に任せる） |
| ロック中のトラック | エラー表示して中止 |
| タイムラインにイン／アウト範囲設定あり | 無視（シーケンス全体を対象） |

### 5.4 結果レポート

処理後、次のサマリーをダイアログ表示：

```
完了しました。

  スナップ済み:  19 本
  スキップ:       4 本（許容範囲外）
  合計:          23 本

                          [ OK ]
```

### 5.5 Undo
- 1 回の実行が Premiere の履歴 1 ステップになること（`app.enableQE()` や履歴 API 併用）
- ユーザーが Cmd/Ctrl+Z を押したら、全テロップが元の位置に戻ること

## 6. 非機能要件

| 項目 | 要件 |
|---|---|
| パフォーマンス | テロップ 500 本規模で実行時間 5 秒以内 |
| 依存 | Adobe 公式 `CSInterface.js` のみ（バンドル同梱） |
| 配布形式 | 署名付き `.zxp` 単一ファイル |
| エラー | エラーはパネル内のステータス領域に日本語で表示 |
| ログ | CEP デバッグコンソール (Chromium DevTools) 経由で確認可 |
| i18n | UI 文言は日本語のみ（v1） |

## 7. アーキテクチャ

### 7.1 構成

Adobe CEP (Common Extensibility Platform) 拡張パネルとして実装。

```
┌─────────────────────────────┐
│ Panel (HTML/CSS/JS)         │  ← ユーザー UI（client/）
│ · index.html / main.js      │
│ · CSInterface.js            │
└────────────┬────────────────┘
             │ evalScript()
             ▼
┌─────────────────────────────┐
│ Host (ExtendScript)         │  ← Premiere Pro API 呼び出し（host/）
│ · SubtitleSync.jsx          │
│   - CA_listTracks()         │
│   - CA_plan(params)         │
│   - CA_execute(params)      │
└─────────────────────────────┘
```

- パネル側とホスト側は JSON 文字列でやり取りする
- ホスト側は ScriptUI を一切使わず、純粋な関数として Premiere API を操作する

### 7.2 リポジトリ構成

```
Clip-Adjust/
├── CSXS/
│   └── manifest.xml              # CEP パネル定義
├── client/                       # パネル UI
│   ├── index.html
│   ├── main.js
│   └── style.css
├── host/
│   └── SubtitleSync.jsx          # Premiere API 操作
├── lib/
│   └── CSInterface.js            # Adobe 公式ライブラリ
├── build/
│   ├── build.sh                  # Mac/Linux 用ビルド
│   ├── build.ps1                 # Windows 用ビルド
│   └── .gitignore                # 自己署名証明書等を除外
├── .github/workflows/release.yml # タグ push で ZXP 自動ビルド
├── .debug                        # 開発時のリモートデバッグ設定
├── docs/requirements.md          # 本書
├── README.md
└── LICENSE
```

## 8. 配布・インストール方式

### 8.1 配布物
- GitHub Releases の Assets に **署名付き `Clip-Adjust-vX.Y.Z.zxp`** を添付
- ZXP は自己署名証明書で署名済（CI で自動署名）

### 8.2 ユーザー導入フロー

1. **ZXPInstaller** （無料・第三者ツール、https://zxpinstaller.com ）を初回のみインストール
2. GitHub Releases から `.zxp` をダウンロード
3. ZXPInstaller 画面に `.zxp` をドラッグ＆ドロップ
4. Premiere Pro を再起動 → **ウィンドウ > 機能拡張 > Clip-Adjust**

### 8.3 ビルド方式

- 開発者: `build/build.sh` または `build/build.ps1` を実行すると
  Adobe `ZXPSignCmd` と自己署名証明書が自動で用意され、`dist/*.zxp` が生成される
- CI: `v*` タグ push で GitHub Actions が同じスクリプトを走らせ、Release に添付する

## 9. バージョニング / リリース

- セマンティックバージョニング (`MAJOR.MINOR.PATCH`)
- バージョンは `CSXS/manifest.xml` の `ExtensionBundleVersion` を単一ソースとする
- `host/SubtitleSync.jsx` の `CA_VERSION` はパネルフッターに表示用（同期させる）
- タグ `vX.Y.Z` を push すると GitHub Actions が ZXP を自動生成し Release に添付

## 10. 将来拡張（v1 非対応 / v2 以降の検討事項）

| 機能 | 優先度 |
|---|---|
| 音声解析による「発話開始点」スナップ（VAD + ffmpeg 同梱） | 高 |
| 複数テロップトラックの一括処理 | 中 |
| OUT 点も吸着するモード | 中 |
| タイムライン選択範囲のみを対象にする | 中 |
| 英語 UI | 低 |
| UXP 版への移行（CEP の将来的な廃止に備える） | 中 |
| スナップ先をベース IN だけでなく OUT にも拡張 | 低 |

## 11. 受け入れ基準（v1 完了条件）

以下すべてを満たすこと：

- [ ] Mac / Windows の Premiere Pro 2024 以降でパネルが起動する
- [ ] パネル UI で 2 つのトラックと許容フレームを指定して実行できる
- [ ] 許容範囲内のテロップのみがスナップされ、範囲外はスキップされる
- [ ] 尺が意図せず変わらない（スライド動作で IN/OUT が同量移動）
- [ ] Cmd/Ctrl+Z で一括 undo できる
- [ ] 署名付き `.zxp` が GitHub Releases から取得でき、ZXPInstaller で一発導入できる
- [ ] 導入フローに OS のセキュリティ警告（Gatekeeper / SmartScreen）を踏まない
- [ ] README の手順だけで非エンジニアが導入・実行できる
